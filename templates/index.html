Nhập thiết bị hàng loạt bằng File CSV

Quy tắc nhập dữ liệu:

  • File CSV mã hóa UTF-8 với dấu phẩy ngăn cách.
  • Tránh trùng lặp mã thiết bị: Các mã trùng trong file hoặc đã có trong hệ thống sẽ được phát hiện và báo lỗi rõ ràng.
